**[EN] Intro**

A meeting invitation often creates work before the meeting starts. Find the address. Install the right software. Create an account. Remember a password. Copy a meeting code. Zoom's famous move was to hide most of that machinery behind one link. The host sends the link, the guest clicks it, and the product treats joining as the first job. Everything else can wait until the person is inside the room.

**[MY] Intro**

Meeting ဖိတ်စာ တစ်စောင်က meeting မစခင်မှာပဲ အလုပ် ပေးတတ်တယ်။ လိပ်စာကို ရှာပါ။ Software အမှန်ကို install လုပ်ပါ။ Account ဖွင့်ပါ။ Password ကို မှတ်မိအောင် လုပ်ပါ။ Meeting code ကို copy လုပ်ပါ။ Zoom ရဲ့ နာမည်ကြီးတဲ့ လုပ်ရပ်က အဲဒီ စနစ် အများစုကို link တစ်ခုနောက်မှာ ဝှက်လိုက်တာပဲ။ Host က link ပို့တယ်။ Guest က နှိပ်တယ်။ Product က ဝင်ရောက်တာကို ပထမဆုံး အလုပ်လို သဘောထားတယ်။ ကျန်တာ အကုန်လုံးက လူ အခန်းထဲ ရောက်တဲ့ အထိ စောင့်လို့ ရတယ်။

---

**[EN] 1. The link carries the invitation**

A Zoom link does more than point to a website. It carries the guest toward a specific meeting. The invitation can travel through email, chat or a calendar event without asking the guest to understand the system behind it. One object holds the place, the moment and the action: click here to join.

**Principle Card — One Object, One Action**
Rules applied: Recognition Over Recall · Single Clear Action
People act faster when the next step is visible and specific. A link removes the need to remember an ID or reconstruct instructions from separate messages.

**[MY] 1. Link က ဖိတ်စာကို သယ်သွားတယ်**

Zoom link က website တစ်ခုကို ညွှန်ရုံပဲ မဟုတ်ဘူး။ Guest ကို meeting အတိအကျ တစ်ခုဆီ သယ်သွားတယ်။ ဖိတ်စာက email၊ chat နဲ့ calendar event တွေထဲ ခရီးသွားလို့ ရတယ်။ နောက်က system ကို guest က နားလည်စရာ မလိုဘူး။ အရာ တစ်ခုတည်းက နေရာ၊ အချိန်နဲ့ လုပ်ရပ်ကို ကိုင်ထားတယ်။ Join ဖို့ ဒီနေရာကို နှိပ်ပါ။

**Principle Card — One Object, One Action**
Applied လုပ်တဲ့ rules: Recognition Over Recall · Single Clear Action
နောက် အဆင့်က မြင်သာပြီး အတိအကျ ရှိရင် လူက ပို မြန်မြန် လုပ်တယ်။ Link က ID တစ်ခု မှတ်မိဖို့နဲ့ သီးခြား message တွေကနေ ညွှန်ကြားချက်တွေ ပြန်ဆက်ဖို့ လိုအပ်ချက်ကို ဖယ်တယ်။

**[EN] 2. A guest does not need to become a user first**

Zoom allows guests to join meetings without first creating a Zoom account, subject to the host's settings. That order matters. A grandparent joining a family call, a candidate joining an interview or a patient joining an appointment does not have to adopt a new product before receiving help. They can complete the human task first.

**Principle Card — Value Before Commitment**
Rules applied: Friction Reduction · Progressive Commitment
People accept setup when they understand the value at the end of it. Letting guests complete the main job first builds trust before asking for a deeper relationship.

**[MY] 2. Guest က အရင် user ဖြစ်စရာ မလိုဘူး**

Zoom က host ရဲ့ setting အလိုက် guest တွေကို Zoom account အရင် မဖွင့်ဘဲ meeting ထဲ ဝင်ခွင့် ပေးတယ်။ အဲဒီ အစီအစဉ်က အရေးကြီးတယ်။ မိသားစု call ထဲ ဝင်တဲ့ အဘိုးအဘွား၊ interview ထဲ ဝင်တဲ့ candidate နဲ့ appointment ထဲ ဝင်တဲ့ လူနာက အကူအညီ မရခင် product အသစ် တစ်ခုကို အရင် လက်ခံစရာ မလိုဘူး။ သူတို့က လူသားချင်း လုပ်ရမယ့် အလုပ်ကို အရင် ပြီးအောင် လုပ်လို့ ရတယ်။

**Principle Card — Value Before Commitment**
Applied လုပ်တဲ့ rules: Friction Reduction · Progressive Commitment
အဆုံးမှာ ရမယ့် အကျိုးကို နားလည်ရင် လူက setup ကို လက်ခံတယ်။ Guest ကို အဓိက အလုပ် အရင် ပြီးခွင့်ပေးတာက ပို နက်တဲ့ ဆက်ဆံရေးကို မတောင်းခင် trust ကို အရင် ဆောက်တယ်။

**[EN] 3. The important controls are hard to miss**

Once inside, a new user's urgent questions are simple. Can people hear me? Can they see me? How do I share? How do I leave? Zoom places familiar controls for mute, video, participants, chat and leaving where users can reach them quickly. Icons, labels and clear states matter because a live meeting is a bad classroom for learning an interface.

**Principle Card — Controls for a Stressed Moment**
Rules applied: Visibility of System Status · Fitts's Law · Error Prevention
People need larger, familiar targets when attention is divided. Clear microphone and camera states prevent the most embarrassing error: believing you are private when you are not.

**[MY] 3. အရေးကြီးတဲ့ control တွေကို လွတ်သွားဖို့ ခက်တယ်**

အထဲ ရောက်သွားရင် user အသစ်ရဲ့ အရေးတကြီး မေးခွန်းတွေက ရိုးရိုးပဲ။ လူတွေ ငါ့ကို ကြားရလား။ မြင်ရလား။ ဘယ်လို share ရမလဲ။ ဘယ်လို ထွက်ရမလဲ။ Zoom က mute၊ video၊ participants၊ chat နဲ့ leave အတွက် ရင်းနှီးတဲ့ control တွေကို user မြန်မြန် ရောက်နိုင်တဲ့ နေရာမှာ ထားတယ်။ Icon၊ label နဲ့ state ရှင်းတာတွေ အရေးကြီးတယ်။ Live meeting က interface တစ်ခု သင်ဖို့ အဆိုးဆုံး စာသင်ခန်းပဲ။

**Principle Card — Controls for a Stressed Moment**
Applied လုပ်တဲ့ rules: Visibility of System Status · Fitts's Law · Error Prevention
Attention ပြန့်နေရင် လူက ပို ကြီးပြီး ရင်းနှီးတဲ့ target တွေ လိုတယ်။ Microphone နဲ့ camera state ရှင်းတာက အရှက်ရဆုံး အမှားကို တားတယ်။ အဲဒီ အမှားက ကိုယ် private ဖြစ်တယ် ထင်ပေမဲ့ တကယ် မဖြစ်တဲ့ အမှားပဲ။

**[EN] 4. The preview gives one last private moment**

Before entering, the user can see and adjust their video and audio state. This small pause gives them control over how they appear. It also catches simple problems while the cost is still low: the camera is covered, the wrong microphone is selected, or the room behind them is not ready.

**Principle Card — Check Before Exposure**
Rules applied: User Control · Feedback · Error Prevention
People relax when they can inspect themselves before becoming visible to a group. A preview turns a surprise entrance into a deliberate one.

**[MY] 4. Preview က နောက်ဆုံး private အချိန် တစ်ခု ပေးတယ်**

မဝင်ခင် user က သူ့ video နဲ့ audio state ကို မြင်ပြီး ပြင်လို့ ရတယ်။ ဒီ ခဏ ရပ်တာက သူ ဘယ်လို ပေါ်မလဲ ဆိုတာကို ထိန်းချုပ်ခွင့် ပေးတယ်။ ကုန်ကျစရိတ် နည်းသေးတဲ့ အချိန်မှာ ရိုးရိုး ပြဿနာတွေကိုလည်း ဖမ်းပေးတယ်။ Camera က ပိတ်ခံနေရတယ်။ Microphone အမှား ရွေးထားတယ်။ နောက်က အခန်းက အဆင်သင့် မဖြစ်သေးဘူး။

**Principle Card — Check Before Exposure**
Applied လုပ်တဲ့ rules: User Control · Feedback · Error Prevention
လူက group တစ်ခုကို မမြင်ရခင် ကိုယ့်ကိုယ်ကို စစ်လို့ ရရင် ပို စိတ်အေးတယ်။ Preview က အံ့ဩစရာ ဝင်ရောက်မှုကို ရည်ရွယ်ပြီး ဝင်တဲ့ ဝင်ရောက်မှု ဖြစ်အောင် ပြောင်းပေးတယ်။

---

**[EN] 5. The door needed a lock after it opened to everyone**

The same openness that made Zoom easy also made a widely shared link risky. Zoombombing showed how uninvited people could enter and disrupt meetings. Zoom responded by strengthening passcodes, waiting rooms and host controls. A passcode can be embedded in the invitation link, while the waiting room lets a host admit people deliberately. The one-click idea survived, but the door gained judgment.

**Principle Card — Friction at the Risk Boundary**
Rules applied: Risk-Calibrated Friction · Trust and Safety
Zero friction is not always good design. The right check belongs where harm can enter, and it should stay light for the invited guest while making unwanted entry harder.

**[MY] 5. လူတိုင်းအတွက် ပွင့်ခဲ့တဲ့ တံခါးမှာ သော့ တစ်ခု လိုလာတယ်**

Zoom ကို လွယ်အောင် လုပ်ခဲ့တဲ့ ပွင့်လင်းမှု တူတူကပဲ ကျယ်ကျယ် မျှထားတဲ့ link ကို အန္တရာယ် ရှိအောင် လုပ်ခဲ့တယ်။ Zoombombing က မဖိတ်ထားတဲ့ လူတွေ ဝင်လာပြီး meeting တွေကို ဘယ်လို နှောင့်ယှက်နိုင်လဲ ပြခဲ့တယ်။ Zoom က passcode၊ waiting room နဲ့ host control တွေကို ပို ခိုင်အောင် လုပ်ပြီး ပြန်တုံ့ပြန်ခဲ့တယ်။ Passcode ကို ဖိတ်စာ link ထဲမှာ ထည့်ထားလို့ ရတယ်။ Waiting room ကတော့ host ကို လူတွေကို ရည်ရွယ်ပြီး ဝင်ခွင့်ပေးခွင့် ပေးတယ်။ One-click အတွေးက ဆက်ရှိနေတယ်။ ဒါပေမဲ့ တံခါးမှာ ဆုံးဖြတ်နိုင်တဲ့ စွမ်းရည် ပါလာတယ်။

**Principle Card — Friction at the Risk Boundary**
Applied လုပ်တဲ့ rules: Risk-Calibrated Friction · Trust and Safety
Friction လုံးဝ မရှိတာက အမြဲ ကောင်း design မဟုတ်ဘူး။ မှန်တဲ့ စစ်ဆေးမှုက ထိခိုက်မှု ဝင်နိုင်တဲ့ နေရာမှာ ရှိသင့်တယ်။ ဖိတ်ထားတဲ့ guest အတွက် ပေါ့ပေါ့ပါးပါး နေပြီး မလိုချင်တဲ့ ဝင်ရောက်မှုကိုတော့ ပို ခက်အောင် လုပ်သင့်တယ်။

**[EN] The honest summary**

Zoom won attention by making the first step almost disappear. The invitation became the interface, guests could join before becoming account holders, and the main controls answered the questions people have under pressure. Growth exposed the weakness in that bargain. An easy link is also an easy link to forward, leak or guess around. Passcodes, waiting rooms and host controls added protection, but they also added waiting, admission work and new chances to lock out the right people. Zoom's lesson is precise: remove friction from the path, then place deliberate friction at the boundary where safety begins.

**[MY] အမှန်အတိုင်း အကျဉ်းချုပ်**

Zoom က ပထမဆုံး အဆင့်ကို ပျောက်လုနီးပါး ဖြစ်အောင် လုပ်ပြီး attention ရခဲ့တယ်။ ဖိတ်စာကိုက interface ဖြစ်လာတယ်။ Guest တွေက account holder မဖြစ်ခင် ဝင်လို့ ရတယ်။ အဓိက control တွေက pressure အောက်မှာ လူတွေ ရှိတဲ့ မေးခွန်းတွေကို ဖြေတယ်။ ကြီးထွားလာတာက အဲဒီ သဘောတူညီမှုရဲ့ အားနည်းချက်ကို ထုတ်ပြတယ်။ လွယ်တဲ့ link က forward လုပ်ရ၊ ပေါက်ကြားရနဲ့ ခန့်မှန်းရ လွယ်တဲ့ link လည်း ဖြစ်တယ်။ Passcode၊ waiting room နဲ့ host control တွေက ကာကွယ်မှု ထပ်ပေးတယ်။ ဒါပေမဲ့ စောင့်ရတာ၊ ဝင်ခွင့် ပေးရတဲ့ အလုပ်နဲ့ လူအမှန်တွေကို ပိတ်မိမယ့် အခွင့်အလမ်း အသစ်တွေလည်း ထပ်ပေးတယ်။ Zoom ရဲ့ သင်ခန်းစာက အတိအကျပဲ။ လမ်းထဲက friction ကို ဖယ်ပါ။ ပြီးရင် လုံခြုံမှု စတဲ့ နယ်နိမိတ်မှာ ရည်ရွယ်ထားတဲ့ friction ကို ထားပါ။
